# Chistecofi — Needle in a Haystack

A TypeScript + React game based on the proverb. One needle is hidden in a triangular haystack of 1,000, 100,000, or 100,000,000 straws.

The haystack is generated from a seed and an index, not from millions of objects. The canvas only draws what is on screen (or a silhouette when you zoom out).

## Run

```bash
npm install
npm run dev
```

Languages: English, Spanish, French, Dutch — detected from the browser, with a manual switcher.
